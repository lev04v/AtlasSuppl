# Wellness CureCare

A polished single-page pharmaceutical trade and healthcare distribution website.

## About Wellness CureCare

Wellness CureCare is a pharmaceutical and healthcare company committed to providing safe, high-quality, and affordable medicines. We focus on innovation, quality, and customer satisfaction while serving healthcare professionals, hospitals, pharmacies, and distributors with reliable products that promote healthier lives and better well-being.

## Installation & Running

### macOS
Install [Node.js](https://nodejs.org/) (v14+), then run:
```bash
npm install --prefix frontend
npm run frontend
```
Visit `http://localhost:5173`

### Windows
Install [Node.js](https://nodejs.org/) (v14+), then run:
```bash
npm install --prefix frontend
npm run frontend
```
Visit `http://localhost:5173`
